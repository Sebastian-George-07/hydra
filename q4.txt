Network and Service Enumeration Using Nmap


Aim
Discover hosts and identify open ports and service versions on an authorized lab target.

Software Required
•	Kali Linux
•	Nmap
•	Owned target VM on a private or Host-only network

Procedure / Commands

1. Install Nmap.

sudo apt update
sudo apt install nmap -y

2. Check Kali interfaces and routes.

ip -br addr
ip route

3. Discover the authorized target host. Replace the placeholder.

nmap -sn <TARGET_IP>

4. Scan common TCP ports on that target.

nmap <TARGET_IP>

5. Identify services and versions.

nmap -sV <TARGET_IP>

6. Scan selected ports only.

nmap -sV -p 22,80,443 <TARGET_IP>

7. Save output for the report.

nmap -sV -oN nmap-results.txt <TARGET_IP>
cat nmap-results.txt

Expected Output
•	Host discovery may report the target as up, depending on firewall settings.
•	Ports are listed as `open`, `closed` or `filtered`.
•	`-sV` may identify service names and versions.
•	A report file named `nmap-results.txt` is created.

Result
Network and service enumeration was performed on an authorized lab target and the results were saved for review.








1. What is Nmap?
Answer: Nmap is a tool used to discover hosts and scan network services.
2. What is a port?
Answer: A port is a logical endpoint used by network applications.
3. What is an open port?
Answer: An open port indicates that a service is listening and accepting connections.
4. What is service enumeration?
Answer: Identifying services and, where possible, their versions on a target system.
5. Which command scans a target IP?
Answer: nmap TARGET_IP
6. What does -sV do in Nmap?
Answer: It attempts to identify service versions.
7. What does -p mean in Nmap?
Answer: It specifies which ports to scan.
8. What is the difference between TCP and UDP?
Answer: TCP provides connection-oriented, reliable delivery. UDP sends datagrams without TCP's delivery guarantees.
