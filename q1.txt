Deploy OWASP WebGoat Using Docker

Aim
Deploy an isolated OWASP WebGoat container and verify its status, published ports and web interface.

Software Required
•	Kali Linux VM with internet access
•	Docker Engine (`docker.io`)
•	Firefox or another browser

Procedure / Commands

1. Update package lists and install Docker.

sudo apt update
sudo apt install docker.io -y

2. Start Docker and enable it at boot.

sudo systemctl enable --now docker
sudo systemctl status docker --no-pager

3. Download the WebGoat image.

sudo docker pull webgoat/webgoat

4. Start WebGoat with ports bound to loopback only.

sudo docker run -d --name webgoat \\
  -p 127.0.0.1:8080:8080 \\
  -p 127.0.0.1:9090:9090 \\
  webgoat/webgoat

5. Verify container state and ports.

sudo docker ps
sudo docker port webgoat

6. If the site does not load, check startup logs.

sudo docker logs --tail 80 webgoat

7. Open WebGoat in Firefox.

http://127.0.0.1:8080/WebGoat

8. Test the endpoint from a terminal.

curl -I http://127.0.0.1:8080/WebGoat

Expected Output
•	`docker ps` shows the container with an `Up` status and a loopback port mapping.
•	The WebGoat login page loads at `http://127.0.0.1:8080/WebGoat` once startup completes.
•	`curl -I` returns an HTTP response; the status can vary by image version and startup state.

Result
WebGoat was deployed in Docker and its local endpoint and port mapping were verified.









1. What is Docker?
Answer: Docker is a platform used to package and run applications in containers.
2. What is a container?
Answer: A container is an isolated environment in which an application runs.
3. What is a Docker image?
Answer: An image is a template used to create a container.
4. What is OWASP WebGoat?
Answer: WebGoat is an intentionally vulnerable web application used for security training.
5. What is the difference between an image and a container?
Answer: An image is the template. A container is the running instance.
6. Which command lists running containers?
Answer: docker ps
7. Which command downloads a Docker image?
Answer: docker pull IMAGE_NAME
8. Why do we use WebGoat?
Answer: To learn web application vulnerabilities safely in a training environment.
